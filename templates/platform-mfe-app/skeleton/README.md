## What was generated

A production-ready React frontend boilerplate:

- **React 19 + Vite 8 + TypeScript (strict)** — fast dev server, optimized
  production build, strict type checking with no unchecked array access.
- **TanStack Router** — type-safe, file-based routing (see `src/routes/`).
  The route tree (`src/routeTree.gen.ts`) is generated by the
  `@tanstack/router-plugin` Vite plugin and **committed** so `npm run
  typecheck` works standalone in CI without a prior build.
- **TanStack Query** — server-state management with sensible defaults and
  devtools in development (`src/app.tsx`).
- **TanStack Table + TanStack Virtual** — a virtualized, sortable, filterable
  table demo at `/table` (`src/features/table-demo/`).
- **React Hook Form + Zod** — a validated form demo at `/form`
  (`src/features/form-demo/`).
- **Radix UI primitives** — accessible dialog, select, dropdown, checkbox,
  switch, tabs, tooltip, and toast building blocks in `src/components/ui/`.
- **UnoCSS + semantic CSS variables** — theme-aware utility classes. Colors
  are CSS custom properties in `src/styles/theme.css`; switch
  `data-theme` on `<html>` to reskin the whole app.
- **Light / dark / system theme** — persisted in localStorage, follows the
  OS preference live (`src/components/theme/`).
- **Clear API boundary** — every network call goes through
  `src/api/client.ts` (typed fetch wrapper, timeout, normalized `ApiError`);
  domain endpoints live in `src/api/`. Components never call `fetch`
  directly.
- **Environment validation** — `src/lib/env.ts` validates `VITE_*`
  variables with Zod at boot and fails fast with a readable message.
- **Loading / empty / error / not-found states** — canonical components in
  `src/components/feedback/`, driven by `QueryBoundary` for TanStack Query
  results.
- **Testing** — Vitest + Testing Library unit/component tests (`npm test`)
  and Playwright browser smoke tests (`npm run test:e2e`) covering boot,
  theming, the table, the form, and the 404 page.
- **Accessibility** — skip link, semantic landmarks, `aria-current` nav,
  focus-visible rings, keyboard-operable controls, and
  `prefers-reduced-motion` support.
- **Responsive layout** — mobile-first shell in `src/components/layout/`.

## Running

```bash
npm ci             # frozen install from the committed package-lock.json
npm run dev        # dev server on http://127.0.0.1:5173
npm run typecheck  # tsc --noEmit (app + node configs)
npm run lint       # eslint
npm test           # vitest run
npm run build      # vite build -> dist/
npm run preview    # serve the production build on http://127.0.0.1:4173
npm run test:e2e   # playwright (builds + previews first)
```

The same steps run in CI on every push and pull request to `main`
(`.github/workflows/ci.yml`), including the Playwright browser smoke suite.
CI installs with `npm ci` (deterministic, fails if `package.json` and
`package-lock.json` drift) and enforces the pinned npm version via the
`packageManager` field (`corepack enable`). When you change dependencies,
run `npm install` locally and commit the updated `package-lock.json`.

## Environment variables

Copy `.env.example` to `.env.local` and adjust as needed. Only `VITE_`
prefixed variables are exposed to the browser; they are validated at boot
by `src/lib/env.ts`:

- `VITE_API_BASE_URL` — absolute base URL of the backend API
  (default `http://localhost:8080/api`). The health card on the home page
  demonstrates the loading / error / retry states when no backend is
  running.
- `VITE_APP_TITLE` — optional display-title override.

## Where product development begins

Add business-domain code under `src/features/`, `src/routes/`, `src/api/`, and
product-owned components. Extend the generated layout rather than creating a
second shell. Product code owns domain rules, data, pages, workflows, and UX.
The platform owns the shared UI primitives, theme foundations, standard
feedback behavior, and SDK contract.

Do not treat frontend code as the authority for authentication security,
authorization enforcement, persistence, audit integrity, tenant isolation, or
compliance. Supply real API/provider implementations behind the documented
contracts. In standalone mode, SDK auth and permissions are unavailable and
permission checks fail closed.
